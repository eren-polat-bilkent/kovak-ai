![CyberShieldAI](https://img.shields.io/badge/CyberShieldAI-Tespit%20Platformu-6366f1?style=for-the-badge)

## Özellikler

- 🎵 **Ses Deepfake** - Klonlanmış ses, sentetik konuşma tespiti
- 🎬 **Video Deepfake** - Yüz değiştirme, dudak senkronizasyonu manipülasyonları
- 🖼️ **Yapay Zeka Görselleri** - DALL-E, Midjourney, Stable Diffusion çıktıları
- 📝 **Yapay Zeka Metni** - ChatGPT vb. ile yazılmış içerikler
